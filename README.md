🧠 Mindora AI

Overview

Mindora AI is an AI-powered mental wellness and psychology learning web app. It helps users learn psychology concepts, reflect on emotions, and interact with an AI assistant in a simple and user-friendly way.
Created by : Muhammad Asim Khan

Problem Statement

Many people find it difficult to understand emotions and access reliable psychology resources. Mindora AI provides easy-to-understand educational guidance using AI.

 Features

. AI Self-Assessment
. AI Companion Chat
. Psychology Learning Assistant
. Google Gemini AI Chat
. Mobile-Friendly Design

AI Feature

Mindora AI uses Google Gemini AI to:

. Answer psychology-related questions
. Explain psychology concepts
. Analyze self-assessment responses
. Provide educational guidance

System Prompt

The AI acts as a supportive psychology learning assistant. It provides educational information, encourages self-reflection, and avoids diagnosing mental health conditions.

Technologies Used

 Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
